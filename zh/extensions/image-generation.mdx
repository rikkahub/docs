---
title: "在 Rikka 中通过文本提示生成图片"
sidebarTitle: "图片生成"
description: "打开 Rikka 的图片生成工作区，使用已配置提供商中的图片模型，通过文本提示生成图片。"
---

Rikka 内置了专用的图片生成工作区，让你可以通过文本提示生成图片，或提供参考图片让模型进行编辑。生成的图片存储在应用内相册中，可以随时保存到设备的相册。

<Note>
  图片生成需要支持图片合成的提供商。支持的选项包括 **DALL-E 3**（OpenAI）、**Imagen 3**（Google）以及你在 Rikka 中配置的任何提供图片生成模型的提供商。请确保你已在**设置 → 提供商**中添加并验证了至少一个此类提供商。
</Note>

## 选择图片生成模型

在生成第一张图片之前，告诉 Rikka 要使用哪个模型。

<Steps>
  <Step title="打开模型设置">
    前往**设置 → 模型**，找到**图片生成模型**选择器。
  </Step>
  <Step title="选择模型">
    选择器会列出所有已配置提供商中支持图片生成的模型。选择你想要的模型——例如，来自 OpenAI 提供商的 `dall-e-3`，或来自 Google 的 `imagen-3.0-generate-002`。
  </Step>
  <Step title="保存">
    你的选择会自动保存。你也可以随时在图片生成界面中使用输入栏的模型选择器来更换模型。
  </Step>
</Steps>

## 打开图片生成界面

点击应用抽屉（主屏幕上的网格图标）中的**图片生成**入口，打开专用工作区。界面底部有两个标签页：

<CardGroup cols={2}>
  <Card title="生成" icon="wand-magic-sparkles">
    输入提示词、调整设置并创建新图片。最近生成的图片会显示在此标签页的顶部。
  </Card>
  <Card title="相册" icon="images">
    浏览所有会话中生成的图片，每张卡片上显示提示词和模型名称。
  </Card>
</CardGroup>

## 通过文本提示生成图片

<Steps>
  <Step title="编写提示词">
    在**生成**标签页底部的输入框中输入描述性文本提示词。你提供的细节越多——主题、风格、光线、构图——输出就越接近你的设想。
  </Step>
  <Step title="调整生成设置（可选）">
    点击**设置（扳手）图标**打开设置面板。你可以配置：

    - **模型**——无需离开当前界面即可切换到其他图片模型。
    - **图片数量**——单次请求生成 1 到 4 张图片。
    - **宽高比**——选择正方形、横向或纵向。
  </Step>
  <Step title="点击发送按钮">
    点击圆形**箭头**按钮。Rikka 将你的提示词发送到所选模型，并在等待结果时显示加载指示器。
  </Step>
  <Step title="查看输出">
    生成的图片会出现在输入栏上方。点击任意图片可打开全屏预览。
  </Step>
</Steps>

<Tip>
  点击右上角的 **+** 图标开始**新会话**，可以清除当前提示词和已生成的图片，重新开始。每个会话保持独立的上下文，与相册历史记录分开。
</Tip>

## 编辑已有图片

部分模型——例如 `dall-e-2` 和某些 Imagen 变体——支持图片编辑，你可以提供参考图片并用提示词描述你想要的更改。

<Steps>
  <Step title="添加参考图片">
    点击输入栏中的**添加图片（+）图标**，从设备相册中选择一张或多张图片。缩略图会出现在文本框上方；点击缩略图上的 **×** 可移除。
  </Step>
  <Step title="描述编辑内容">
    编写提示词说明要应用的更改，例如：*"将背景更换为海上日落"*。
  </Step>
  <Step title="点击发送按钮">
    当存在参考图片时，Rikka 会调用提供商的图片编辑端点，而非标准生成端点。
  </Step>
</Steps>

<Warning>
  并非所有图片模型都支持编辑。如果你选择的模型仅支持生成，当你尝试附带参考图片提交时，Rikka 会返回错误。请切换到支持编辑的模型（查看你的提供商文档），或移除参考图片以执行标准生成。
</Warning>

## 使用相册

你生成的每张图片都会自动保存到 Rikka 的应用内相册。打开**相册**标签页浏览历史记录。

每张相册卡片显示：
- 图片缩略图
- 使用的模型
- 提示词的截断版本

在卡片的操作栏中，你可以：

| 操作 | 效果 |
|--------|--------|
| **复制**（剪贴板图标） | 将完整提示词文本复制到剪贴板，方便你复用或修改。 |
| **保存**（软盘图标） | 将图片保存到设备的相册/媒体库。 |
| **删除**（垃圾桶图标） | 从相册中移除图片并从内部存储中删除文件。 |

点击缩略图可打开支持双指缩放的全屏预览。

<Note>
  图片存储在 Rikka 的私有内部存储中，直到你明确点击**保存**将其导出到设备的媒体库。卸载 Rikka 将永久删除所有未外部保存的图片。
</Note>

## 获得更好效果的技巧

<Accordion title="编写有效的提示词">
  - 具体描述主题：*"一只红色狐狸坐在黄昏时分的雪地森林中"* 比 *"一只狐狸"* 效果好得多。
  - 指明艺术风格或媒介：*"油画"*、*"照片级真实感"*、*"水彩素描"*。
  - 描述氛围或气氛：*"戏剧性光线"*、*"柔和的粉彩色调"*、*"电影级构图"*。
  - 如果模型支持负面提示词，请使用设置面板排除不需要的元素。
</Accordion>

<Accordion title="选择合适的宽高比">
  - **正方形**——社交媒体帖子、头像、产品展示。
  - **横向（16:9）**——桌面壁纸、场景插图、横幅。
  - **纵向（9:16）**——手机壁纸、海报、角色立绘。
</Accordion>

<Accordion title="控制 API 费用">
  图片生成 API 通常按生成的图片数量收费。在迭代提示词时，将**图片数量**设置保持为 `1`，等你满意风格和构图后再增加数量。
</Accordion>
