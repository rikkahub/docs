Rikka 将所有主流 AI 服务商整合在一款精致的 Android 应用中。你不再需要在多个应用和浏览器标签页之间切换——只需配置一次自己的 API 密钥，即可在同一个熟悉的界面中与 OpenAI、Google Gemini、Anthropic Claude 或任何兼容 OpenAI 的端点对话。Rikka 使用 Kotlin 和 Jetpack Compose 原生构建，运行流畅、响应迅速，在 Android 设备上体验自然。

## 为什么选择 Rikka？

Rikka 的设计围绕一个核心理念：你应该掌控自己的 AI 使用体验。你使用自己的 API 密钥，选择自己的模型，对话内容完全私密。没有订阅费，没有中间商，没有供应商锁定。
