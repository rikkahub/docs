Rikka 让你完全掌控应用的外观和体验。你可以让 Android 根据壁纸自动生成配色方案，从精选的内置主题中挑选，或者使用 HSL 色彩选择器设计完全自定义的调色板。显示选项允许你调整字体大小、消息密度、代码块行为等——所有设置均存储在本地设备上。

## 颜色与主题

### 动态取色

动态取色功能利用 Android 的 Material You 系统，根据你当前的壁纸自动生成 Rikka 的整套配色方案。当你更换壁纸时，Rikka 的强调色会自动跟随变化。

<Tip>
  动态取色需要 Android 12 或更高版本。在较旧的设备上，该开关会隐藏，Rikka 将回退到所选的预设或自定义主题。
</Tip>

启用动态取色的步骤：

<Steps>
  <Step title="打开设置">
    在主屏幕上点击**设置**图标。
  </Step>
  <Step title="前往偏好设置 → 主题">
    选择**偏好设置**，然后点击**主题**。
  </Step>
  <Step title="开启动态取色">
    启用**动态取色**开关。Rikka 的界面会立即采用从壁纸提取的调色板。
  </Step>
</Steps>

当动态取色处于激活状态时，预设和自定义主题的选择将被忽略。关闭动态取色即可使用它们。

---

### 深色模式和 AMOLED 深色模式

Rikka 默认跟随系统的深色/浅色模式偏好。你还可以启用 **AMOLED 深色模式**，使用纯黑背景，在 OLED 屏幕上更加省电。

启用 AMOLED 深色模式的步骤：

<Steps>
  <Step title="打开设置 → 偏好设置 → 主题">
    导航到**设置 → 偏好设置 → 主题**。
  </Step>
  <Step title="启用 AMOLED 深色模式">
    开启 **AMOLED 深色模式**。在深色模式下，背景会切换为纯黑色。
  </Step>
</Steps>

### 预设主题

Rikka 内置了五款精心设计的主题。每款主题都有专属的浅色和深色配色方案，完全符合无障碍标准，并满足 Material You 的对比度要求。

<CardGroup cols={3}>
  <Card title="樱花" icon="circle">
    灵感来自樱花的柔和粉色。这是默认主题。
  </Card>
  <Card title="海洋" icon="circle">
    取自深海的清凉蓝色和青色。
  </Card>
  <Card title="春日" icon="circle">
    唤起新生和晴空的清新绿色。
  </Card>
  <Card title="秋韵" icon="circle">
    温暖的琥珀色和秋季的大地色调。
  </Card>
  <Card title="黑夜" icon="circle">
    针对 AMOLED 优化的高对比度深色优先调色板。
  </Card>
</CardGroup>

应用预设主题的步骤：

<Steps>
  <Step title="关闭动态取色">
    预设主题仅在**动态取色**关闭时可用。
  </Step>
  <Step title="打开设置 → 偏好设置 → 主题 → 主题设置">
    点击**主题设置**以打开主题选择器。
  </Step>
  <Step title="选择一个预设">
    点击任意预设主题卡片。应用会立即更新——无需重启。
  </Step>
</Steps>

### 自定义主题

使用 HSL（色相、饱和度、亮度）色彩选择器指定主色、辅助色和第三色，创建你自己的调色板。你还可以将主题导出为 JSON 进行分享，或导入他人的主题。

<Steps>
  <Step title="打开主题设置">
    前往**设置 → 偏好设置 → 主题 → 主题设置**。
  </Step>
  <Step title="添加新的自定义主题">
    点击**添加**按钮，为你的主题输入一个名称。
  </Step>
  <Step title="设置你的颜色">
    使用 HSL 滑块选择主色、辅助色和第三色。你也可以直接输入 HSL 值（例如 `hsl(267 36% 48%)`）。调整滑块时，调色板的实时预览会同步更新。
  </Step>
  <Step title="保存主题">
    点击**保存**。你的自定义主题会和预设主题一起出现在主题列表中，点击即可激活。
  </Step>
</Steps>

<Tip>
  你可以将自定义主题导出为 JSON 来分享，或者导入朋友的主题。点击任意自定义主题旁边的复制图标即可将其 JSON 复制到剪贴板。要导入主题，请点击**导入**，然后将 JSON 粘贴到弹出的对话框中。
</Tip>

<Note>
  编辑或删除自定义主题会立即生效。如果你删除了当前正在使用的自定义主题，Rikka 会恢复到默认的樱花预设。
</Note>

## 显示设置

显示设置让你控制聊天视图中显示的信息以及内容的渲染方式。在**设置 → 偏好设置 → 显示**中访问。

### 消息显示

<Accordion title="用户头像和昵称">
  - **显示用户头像** — 在你的消息旁边显示头像气泡。
  - **用户昵称** — 设置在对话中显示的名称。
</Accordion>

<Accordion title="助手气泡和透明度">
  - **显示助手气泡** — 用彩色气泡包裹助手消息，而不是显示纯文本。
  - **气泡透明度** — 拖动滑块控制气泡背景的透明程度。
</Accordion>

<Accordion title="模型信息">
  - **显示模型图标** — 在每条助手消息旁显示提供商图标。
  - **显示模型名称** — 在每条助手回复下方显示模型名称。
</Accordion>

<Accordion title="时间戳和 Token 用量">
  - **在消息中显示日期/时间** — 在每条消息后附加时间戳。
  - **显示 Token 用量** — 在每次回复后显示提示和补全的 Token 数量。
</Accordion>

<Accordion title="思考内容">
  - **显示思考内容** — 当模型生成思维链推理时，显示思考内容块。
  - **自动折叠思考** — 在回复生成完成后自动折叠思考内容块。
</Accordion>

### 字体设置

<ParamField path="Font Family" type="select">
  在**默认**（系统无衬线字体）、**衬线体**、**等宽体**或**自定义**之间选择。选择**自定义**会提示你从设备导入字体文件。
</ParamField>

<ParamField path="Font Size" type="slider">
  调整聊天字体大小。拖动滑块时会实时预览效果。
</ParamField>

### 代码块设置

<Accordion title="代码显示选项">
  - **自动换行** — 在代码块内自动换行长行，而不是水平滚动。
  - **自动折叠** — 默认折叠超出视口高度的代码块。
  - **显示行号** — 在每行代码前显示行号。
</Accordion>

### 渲染

- **LaTeX 渲染** — 启用或禁用消息中使用 LaTeX 语法的数学表达式渲染。
- **模糊效果** — 对某些界面元素应用轻微的模糊效果，营造毛玻璃外观。
