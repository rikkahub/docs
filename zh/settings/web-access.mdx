---
title: "通过局域网中的任意浏览器访问 Rikka 聊天界面"
sidebarTitle: "Web 访问"
description: "在 Rikka 内运行本地 HTTP 服务器，让你在同一 Wi-Fi 网络下的任意桌面或移动浏览器上使用完整的聊天界面。"
---

Rikka 可以直接在你的 Android 设备上运行一个轻量级 HTTP 服务器。服务器启动后，同一局域网内的任何浏览器——你的笔记本电脑、平板电脑或另一部手机——都可以打开 Rikka 的聊天界面，无需安装任何东西。应用仍然运行在你的手机上，Web 界面只是一个访问窗口。

<Note>
  Web 服务器仅在 Rikka 在你的 Android 设备上运行时有效。关闭或强制停止应用会关闭服务器。一个持久的前台通知会在应用处于后台时保持服务器运行。
</Note>

## 启动服务器

<Steps>
  <Step title="打开 Web 访问设置">
    在 Rikka 中，前往**设置 → Web 访问**。
  </Step>
  <Step title="配置端口">
    在**端口**字段中输入端口号。默认值为 **8080**。可使用 1024 到 65535 之间的任意值。服务器运行时无法更改端口。
  </Step>
  <Step title="选择网络可见性">
    如果你只希望从设备本身访问服务器（适用于 ADB 端口转发），请开启**仅本机访问**。关闭此选项则允许 Wi-Fi 网络中的其他设备访问。
  </Step>
  <Step title="设置访问密码（推荐）">
    在**访问密码**字段中输入密码。参见下方的[保护服务器安全](#保护服务器安全)。
  </Step>
  <Step title="启动服务器">
    点击**启动**按钮。Rikka 会请求通知权限，在 Android 15 及更高版本上还会请求本地网络权限，然后启动服务器。
  </Step>
</Steps>

## 查找服务器 URL

服务器运行后，Web 访问页面会显示可用地址：

| 地址类型 | 显示条件 | 示例 |
|---|---|---|
| **局域网地址** | 仅本机访问已关闭 | `http://192.168.1.42:8080` |
| **mDNS 地址** | 仅本机访问已关闭且 mDNS 可用 | `http://android-device.local:8080` |
| **本机地址** | 始终显示 | `http://localhost:8080` |

点击任意地址行即可复制到剪贴板。提示消息会确认复制成功。在同一网络的任何浏览器中打开该 URL 即可。

<Tip>
  mDNS 地址（`.local`）更易于输入，在大多数家庭网络上无需知道设备 IP 即可可靠工作。如果无法解析，请回退到局域网地址。
</Tip>

## 保护服务器安全

<Warning>
  如果你将服务器暴露到本机之外（即**仅本机访问**已关闭），局域网内的任何人都可以访问聊天界面。请设置访问密码以防止他人未经授权访问你的对话和 AI 提供商密钥。
</Warning>

Rikka 使用基于 JWT 的认证来保护服务器：

<Steps>
  <Step title="输入访问密码">
    在 Web 访问设置页面的**访问密码**字段中输入密码。
  </Step>
  <Step title="启用 JWT 认证">
    开启**启用 JWT 认证**。此开关仅在密码字段非空时可用。清空密码会自动禁用 JWT 认证。
  </Step>
  <Step title="在浏览器中认证">
    首次打开服务器 URL 时，Web 界面会提示你输入密码。验证成功后，浏览器会话中会存储一个 JWT 令牌，在令牌过期前无需再次输入。
  </Step>
</Steps>

## 配置参考

<ParamField path="Port" type="integer" default="8080">
  HTTP 服务器监听的 TCP 端口。必须在 1024 到 65535 之间。如果值超出范围会显示错误状态。服务器运行时无法更改。
</ParamField>

<ParamField path="Localhost Only" type="boolean" default="false">
  启用时，服务器绑定到 `127.0.0.1`，只能从设备本身访问。禁用时，服务器绑定到所有网络接口，可以从同一网络中的其他设备访问。服务器运行时无法更改。
</ParamField>

<ParamField path="Enable JWT Auth" type="boolean" default="false">
  要求每个请求携带签名的 JWT 令牌。令牌在使用**访问密码**登录时签发。仅在访问密码字段非空时可用。
</ParamField>

<ParamField path="Access Password" type="string" default="">
  用户在浏览器中获取 JWT 令牌时必须输入的密码。清空此字段会自动禁用 JWT 认证。请像对待其他敏感凭据一样妥善保管。
</ParamField>

## 停止服务器

点击 Web 访问设置页面上的**停止**按钮。前台服务和通知会被关闭，所有活跃的浏览器会话将立即断开连接。

你也可以通过在 Android 通知栏中关闭持久通知来停止服务器。
